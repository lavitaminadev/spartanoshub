# Incidentes

Aquí solo se registran eventos que realmente ocurrieron.

No registrar como incidente:
- riesgos futuros;
- hipótesis;
- errores detectados solo en QA;
- mejoras;
- pendientes de negocio.

## Convención
INC-YYYY-NNN

## Campos mínimos
- Fecha y hora real
- Ambiente
- Impacto
- Síntoma
- Evidencia
- Causa confirmada o "no confirmada"
- Mitigación
- Corrección
- Prevención
- Estado
- Referencias a commits / QA / riesgos
