# Riesgos

Un riesgo es algo que podría ocurrir, pero no ha ocurrido necesariamente.

No asignar fecha de incidente a un riesgo.

## Convención
RISK-NNN

## Campos
- Fecha de identificación
- Descripción
- Condición disparadora
- Probabilidad
- Impacto
- Mitigación
- Estado
- Incidente asociado, si alguna vez ocurre
